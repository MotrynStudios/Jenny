# Security policy

## Supported versions

Security fixes are made against the current default branch. Older copies may not receive updates.

## Reporting a vulnerability

Do not report security issues in a public issue. Contact the repository owner privately through GitHub and include the affected version, impact, and steps to reproduce. Do not include live bot tokens, provider keys, private messages, or server exports in the report.

If a credential was committed or shown in logs, revoke and replace it immediately. Removing the visible text does not invalidate a leaked credential.
