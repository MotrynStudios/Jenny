# Security policy

Security fixes target the current default branch.

Use [GitHub private vulnerability reporting](https://github.com/MotrynStudios/Jenny/security/advisories/new). If the form is unavailable, contact **theinevitableinvincible** on Discord or email [motrynstudios@gmail.com](mailto:motrynstudios@gmail.com). Include the affected version, impact, and steps to reproduce. Leave live credentials, private messages, and server exports out of the report.

If a token or API key was exposed, revoke and replace it with its provider. Removing the text from a commit or log does not invalidate the credential.

Keep the local voice API on loopback. See [storage and privacy](CONFIGURATION.md#storage-and-privacy) for data that Jenny saves and sends to configured providers.
